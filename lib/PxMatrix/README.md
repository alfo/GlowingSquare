# PxMatrix 1.8.2, vendored

[PxMatrix](https://github.com/2dom/PxMatrix) by Dominic Buchstaller, BSD licence
(license.txt). Its last release was 1.8.2 in May 2020 and it no longer compiles
on Arduino core 3 / ESP-IDF 5. It is the only driver that works with Brian
Lough's ESP32 Matrix Shield (Mini 32), which wires a single colour line, so
Glowing Square keeps a copy here with the smallest changes that make it build.
Every change is marked `// GS:` in PxMatrix.h.
