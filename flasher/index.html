Web Flasher

Flash the firmware straight from your browser

How it works

  1. Connect the board to this computer with a data USB cable.
  2. Pick your board above and click Install. A board already running this firmware is offered Update, which keeps its settings.
  3. Choose the serial port and confirm.
  4. When it is done, enter your WiFi right here. Or skip that: the board opens a setup WiFi of its own you can join from a phone.
This browser cannot talk to USB devices. Please use Chrome or Edge on a desktop. No USB access here. Open this page over HTTPS.
Flashing fails with "Failed to initialize"? Close anything else using the port (Arduino IDE, a serial monitor, another flasher tab) and plug straight into the computer, no hub. Still failing: hold the board's BOOT button, press and release RST (or EN), release BOOT, then click Install again.
